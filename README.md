# Sales-Analysis-SQL
Analyzing Target sales using SQL and Tableau using queries and performance dashboard. This project visualizes critical insights from Target dataset, focusing on customer behavior, revenue breakdown, payment trends, and delivery performance.

In this analysis, looked at the revenue contribution by product category, monthly trend of late deliveries, customer count by state, product categories vs late deliveries and Payment type distribution

Data Source: https://www.kaggle.com/datasets/devarajv88/target-dataset/data


## **Customer Analysis**
- Total unique customers analyzed: 99,444
- Highest customer count by state: SP (São Paulo) with 41,746 customers. Other notable states: RJ, MG, RS, PR
- Late deliveries peaked between Jan–Mar 2018

## **Revenue by Category**
- Top 3 contributing product categories are:
  1. Health & Beauty – 11.91%
  2. Watches Present – 10.78%
  3. Bed Table Bath – 10.26%

## **Payment Trends**
- Most preferred payment method are:
  1. Credit Card (76.94%)
  2. Others include: UPI (19.9%)
  3. Voucher (3.89%)
  4. Debit Card (1.54%)

## **Delivery Performance**
- Categories with highest late deliveries are:
  1. Bed Table Bath (10.54%)
  2. Automotive (4.25%)
  3. Babies (3.46%)
